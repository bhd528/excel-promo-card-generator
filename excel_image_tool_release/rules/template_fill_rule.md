# 模板填写规则

- **产品**：使用 `B1`，只保留商品名称；删除 `【】` 等外层符号，并去掉容量、规格、件数等信息。两个商品用 `+` / `＋` 连接时必须保留加号；型号/版本类内容如 `2.0`、`5.0`、`8JS4` 保留。
- **规格**：不再从 `A4` 提取。规格来源改为 A 列中出现“规格”相关字样的下一行单元格；该单元格内容直接作为规格字段来源。若该单元格中出现多个规格候选，则取最大的或最多的，例如 `20ml/瓶；20ml/瓶*2` 取 `20ml/瓶*2`；只有一个就照抄；没有则填 `/`。
- **页面价**：从 `A4` 的“页面价”区域提取价格金额本身，只写价格，不写规格，例如 `110元`；关键数据中的“到手价”暂时不对应这个字段；如果出现多个页面价，取最大值。
- **详情券**：从 `A4` 的“详情页领**券”相关内容提取金额，例如 `10元`；没有则填 `/`。
- **拍**：从 `A4` 提取拍几件/几瓶等数量，例如 `1`、`1瓶`；没有则填 `/`。
- **定金**：从 `A4` 提取“定金”金额；如果有多个，取最大值；不要误识别“免定金”；像 `50/100` 这种多档结果取 `100元`。
- **尾款**：从 `A4` 提取“尾款”金额；如果有多个，取最大值；像 `320/350` 这种多档结果取更大的金额。
- **品类券**：只在出现 `美妆券`、`生活券`、`美妆惊喜券`、`精致生活券`、`服饰天降券`、`天猫国际券` 时填写；保留券名、门槛和减免金额，例如 `生活券满200-16元`；没有则填 `/`。
- **消费券**：只在出现 88VIP 消费券时填写减免金额，输出格式固定为 `预估减XX元`；如果原文是区间金额，如 `减10.78~16.78元`，取较大的边界；如果出现多个消费券候选，在所有候选里取最大减免值；没有则填 `/`。
- **其他优惠**：只提取 `购物金充值`、`购物金充`、`充购物金`、`购物金`、`红包补贴`、`天猫返现卡` 对应的优惠短句；不要把同一行里的 `88VIP消费券`、`免定金`、`到手价`、`最终到手价`、`含赠到手` 一起写入；仅有提示词但无金额时不填写。
- **预估到手价**：提取优惠叠加后的最后一个“到手...”结果；如果“到手”和金额跨多行，也按同一段内容识别；保留容量、毫升数、瓶量等说明；如果包含 `折合...`，从 `折合` 开始另起一行；不重新计算价格。
- **文本清洗**：自动忽略 Excel 中混入的不可见格式控制字符或异常控制字符，避免输出方块乱码。

# 制图规则

- 使用新模板 `输出模板_new.jpg`。
- 所有字段值避开模板内已有字段名和冒号，不压字、不贴边、不覆盖装饰元素。
- 空值统一填 `/`。
- `预估到手价` 文字需要带黄色背景。
- 字号策略：
  - `产品`、`预估到手价`：按字数自动调整，最大 `40`
  - `规格`：按字数自动调整，范围 `18-32`
  - 其他字段：按字数自动调整，最小 `34`
